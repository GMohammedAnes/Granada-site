The L'Essence d'Andalousie first batch starts with 86 of 100 units reserved (14 remaining). One shared 24-hour countdown begins at the first public campaign request, not separately for each visitor. Each accepted pre-order consumes one unit, and the first batch stops accepting pre-orders at 100.

**Why:** The user supplied the 86% and 14 remaining figures, then chose a first-public-launch countdown and a live meter capped at 100.

**How to apply:** Keep the baseline and cap aligned across the campaign API and storefront. Do not reset the timer per browser or change the batch size without confirming the new launch stock.
